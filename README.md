# Space Shooter

A 2D space shooter game built with Godot 4.6.

## Prerequisites

- [Godot Engine 4.6](https://godotengine.org/download/) (Forward Plus renderer)

## How to Run

1. Clone this repository
2. Open Godot Engine
3. Click **Import** and navigate to the project folder
4. Select the `project.godot` file and click **Import & Edit**
5. Press **F5** (or click the Play button) to run the game

## Controls

| Action  | Key        |
|---------|------------|
| Move    | Arrow Keys |
| Shoot   | Space      |
| Pause   | Escape     |
| Restart | Space (on game over screen) |
